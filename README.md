# Character Variant Folders

Устанавливаемое расширение SillyTavern для группировки нескольких версий одного
персонажа в раскрывающиеся папки. Внутри папки видны аватар, версия карточки и
полный текст «примечаний от создателя».

## Возможности

- ручные папки, сохраняемые в пользовательских настройках SillyTavern;
- автоматическая группировка имен вроде `Alice v2`, `Alice (GPT-4)` и
  `Alice [alternate]`;
- поиск по названиям папок, персонажам и заметкам автора;
- сортировка персонажей, папок и групп по имени или дате в обоих направлениях (по умолчанию — последнее использование);
- переход к персонажу обычным кликом по вариации;
- режим распределения карточек по папкам;
- отдельный раздел для групповых чатов — группы больше не пропадают;
- сворачивание раздела «Группы» кликом по заголовку с сохранением состояния;
- вложенные папки групп (путь можно вводить через `/` или создавать кнопкой внутри папки);
- автоматические подпапки для групп с одинаковым составом персонажей;
- отсутствие изменений в ядре SillyTavern.

## Установка через диспетчер расширений

1. Опубликуйте содержимое этой папки как отдельный Git-репозиторий.
2. В SillyTavern откройте **Extensions → Install extension**.
3. Вставьте HTTPS URL репозитория и подтвердите установку.
4. Перезагрузите страницу.

После установки в верхней панели списка персонажей появится кнопка с иконкой
папок. Нажмите ее, затем используйте кнопку **Создать папку** и режим
**Распределить персонажей по папкам**.

В этом же режиме у каждой группы появляется выбор папки. Кнопка папки в заголовке
раздела «Группы» создаёт корневую папку, а кнопка внутри существующей папки —
подпапку. Нераспределённые группы с полностью одинаковым составом участников
собираются в автоматическую подпапку.

SillyTavern устанавливает сторонние расширения именно из Git URL, поэтому для
установки через встроенный диспетчер репозиторий должен быть доступен самому
серверу SillyTavern.
